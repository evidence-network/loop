 SAME OPERATOR, TWO ECOSYSTEMS (stapling): one commitment per key + controller binding, side by side
   commitment(key A, mesh)  +  commitment(key B, Goose/deal)  +  binding(A,B -> controller C)  -> never merged

 (mesh peers: endpoint is mesh:<node_id>). Advertise only changes first contact by a stranger.
